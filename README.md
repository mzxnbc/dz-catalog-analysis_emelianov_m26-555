# Аналитика каталога стримингового сервиса

Учебный проект на Python 3.12. Реализованы задания по переменным и числам,
условиям и `match`, циклам, строкам, спискам, словарям, множествам,
итераторам и генераторам, а также итоговый консольный отчет.

## Запуск

Требуется Python 3.12 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run python catalog_analysis.py
```

## Проверка качества кода

```bash
uv run ruff check .
```

## Структура

- `catalog_analysis.py` — данные каталога и решения всех этапов.
- `pyproject.toml` — настройки проекта и Ruff.
- `tests/test_catalog_analysis.py` — базовые автоматические проверки.
